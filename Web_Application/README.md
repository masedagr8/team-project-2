# Web Application

## Pre-requisites
python3 -m pip install uvicorn fastapi

# Launching and Connecting
Run the application using "python3 main.py"

Once the application is running, you can access it via "127.0.0.1:8000" in any webbrowser. 
This should bring a web page where there is a button to refresh images. 
This will fetch image data from this directory and send it to the user's browser
